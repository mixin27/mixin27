A native Android weather application built with Jetpack Compose, designed to present forecast information in a clean, glanceable format.

## Features

- Current conditions alongside daily and hourly forecasts.
- Remote forecast data mapped into a focused mobile UI.
- Local persistence with Room to keep recent data available between sessions.

## Technology

The app uses Kotlin, Jetpack Compose, REST APIs, and Room, with an emphasis on a modern Android architecture and responsive state-driven screens.
