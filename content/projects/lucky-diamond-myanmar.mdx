An internal cash-request app for **Lucky Diamond Myanmar**, created to make staff requests easier to submit and review.

## Workflow

- Captures cash-request details in a clear mobile form.
- Keeps requests organized for follow-up and approval workflows.
- Provides a focused internal experience instead of relying on informal, manual requests.

## Technology

Built with Flutter, Riverpod, AutoRoute, and SOAP API integration to work with the organization's existing services.
