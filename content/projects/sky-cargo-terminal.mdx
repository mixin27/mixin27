An operations app for freight forwarders using **Sky Cargo Terminal**, formerly known as Mingaladon Cargo Service.

## What it supports

- Booking and reviewing terminal appointments from a mobile workflow.
- Keeping appointment details accessible for busy forwarding teams.
- Guiding users through service-related steps with a focused, role-specific interface.

## Implementation

Built with Flutter, BLoC, AutoRoute, and SOAP API integrations to work with the terminal service's existing systems.
